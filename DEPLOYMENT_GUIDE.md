# Deployment checklist

## GitHub
1. Create a new public GitHub repository named `customer-engagement-retention-analytics`.
2. Upload all files from this folder.
3. Confirm `app.py`, `requirements.txt`, `README.md`, and `data/European_Bank.csv` are in the repository.

## Streamlit Community Cloud
1. Sign in with GitHub.
2. Create a new app.
3. Select this repository.
4. Select the `main` branch.
5. Set main file path to `app.py`.
6. Deploy.

## Report
Upload the final research paper PDF to Google Drive and set General Access to "Anyone with the link" (Viewer).

## Feedback video
Record a 2–4 minute walkthrough of the dashboard, upload to YouTube as Unlisted, and copy the HTTPS share URL.
